ℹ️ About ALLIED Digital Library

ALLIED Digital Library is an educational web application designed to help students learn, read, practice and improve their knowledge through digital learning resources.

🎯 Our Objective

The main objective of ALLIED Digital Library is to provide students with an easy-to-use platform for accessing educational resources and practicing different subjects.

📚 What We Provide

  • 📖 Educational learning materials
  • 💻 Programming tutorials
  • 📝 Online practice tests
  • 🏆 Practice points
  • 📊 Student dashboard
  • 🔖 Saved books

💻 Technologies Used

HTML, CSS, JavaScript and Firebase are used to develop the application.
